# Историческое описание Gist

Ниже сохранено прежнее описание для истории. Его адреса Gist и инструкции автообновления после миграции не действуют. Актуальная инструкция — README.md.

# Okdesk: шаблоны и префикс оборудования в теме

Версия 1.7.60. Автор: Jeronimo701.

Secret Gist: доступен любому владельцу ссылки; это не private-хранилище.

Установка: откройте ссылку «Установить» и подтвердите установку в Tampermonkey. Для уже установленной локальной копии один раз переустановите скрипт с этой ссылки, чтобы добавить адрес обновлений. Имя и namespace сохранены; сохранённые настройки не выгружаются в Gist.

Будущие обновления: изменять тот же файл в этом Gist и повышать @version. Адреса @updateURL/@downloadURL указывают на текущий raw-файл без привязки к commit. Автообновления зависят от настроек Tampermonkey и отдельно не проверены в установленном расширении.

Сохранённые настройки, API-токены, логины и пароли пользователя в Gist не включены. Нельзя включать несколько вариантов Okdesk field filler одновременно на одной странице: выбирайте нужный вариант.

JavaScript прошёл node --check; автоматическая проверка секретов и дополнительная проверка фиксированных URL выполнены. В реальных рабочих вкладках скрипты в этой передаче не запускались.

Из шаблона удалён фиксированный URL вложения с токеном; оставлена главная страница справочного сайта. Patch-версия повышена.
